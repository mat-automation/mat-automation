- 2x Minisforum MS-01, PVE (Intel i5 and i9, each 48GB RAM)
- 1x HUNSN RJ42, PVE (Intel N100, 32GB RAM)
- 1x HUNSN RJ03, PBS (Intel N5105, 32GB RAM)
